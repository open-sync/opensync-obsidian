OpenSync for Obsidian

Test build · syncs through __HOST__ on your tailnet

There is no app to download. This is a plugin that runs inside Obsidian. Install Obsidian from the App Store or Play Store first, make or open a vault, then come back here.

Notes weigh almost nothing — a 500-note vault is about 5 MB — so carrying them is free. Attachments are the only part that costs real money to keep, so they are the part that is paid for. Nothing is ever deleted by a plan: a file the plan does not carry simply stays on the device it is already on.

This build is pointed at a relay on the MacBook, so it behaves as the paid product does — and its settings pane has a Plan control so you can be either tier. That control does not exist in a release.

Get the plugin

Download opensync-plugin.zip __ZIP_SIZE__ · unzips to a folder called opensync

iPad

  1. Tap the button above. Safari saves it to Files → Downloads.
  2. Open Files, tap the zip once — it unzips beside itself.
  3. Go to On My iPad → Obsidian → your vault → .obsidian → plugins. If plugins is not there, make it.
  4. Drag the opensync folder into it.
  5. In Obsidian: Settings → Community plugins → turn off Restricted mode, then enable OpenSync. Reload the vault if it does not appear.

Android

  1. Tap the button above, then open the download.
  2. Extract it with your file manager.
  3. Move the opensync folder into <vault>/.obsidian/plugins/ — turn on “show hidden files” if .obsidian is not visible.
  4. In Obsidian: Settings → Community plugins, turn off Restricted mode, enable OpenSync.

MacBook

One line, with the vault path filled in:

curl -sL __PAGE__opensync-plugin.zip -o /tmp/p.zip && unzip -oq /tmp/p.zip -d "$VAULT/.obsidian/plugins/"

Set VAULT first, e.g. export VAULT=~/Documents/MyVault. Then enable it under Settings → Community plugins.

Point it at the relay

Already filled in on a fresh install — check it matches, in Settings → OpenSync:

Relay address__RELAY_WS__
Storage address__RELAY_HTTP__
Every device has to be signed into the same tailnet for those to resolve. If a sync says it cannot reach the relay, that is the first thing to check.

First device, then the others

On the MacBook, once

  1. Settings → OpenSync, press Generate beside Vault key, then beside Account key.
  2. Press Recovery kit → Show it and photograph it. It is the only way back if every device is lost.
  3. Make a note. The status bar should reach OpenSync: up to date.

On the iPad and the phone

  1. On the MacBook: Add a device → Show a code.
  2. On the iPad, scan the QR with the camera. On the phone, same.
  3. Or paste the opensync://pair… line into Join from a code and press Join.

One code, one device, one attempt — right or wrong. Show a new one for the second device.

What to try

Ticks are kept in this browser, per device.

If something goes wrong

“nothing answered that code”The code was already used, or the device cannot reach the relay. Show a new one.
Status bar says “error”Relay unreachable — check Tailscale is connected on that device.
“quota exceeded”The account is not admitted on the relay, or it is genuinely full.
Attachment not syncingExpected on Free. The pane lists what is held back.
Plugin not listedRestricted mode is on, or the folder is in the wrong place. It must be .obsidian/plugins/opensync/ with all three files in it.
